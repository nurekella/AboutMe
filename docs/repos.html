377 репозиториев из моих звёзд, разобранных по назначению: чему учиться, где практиковать руками, что открыть перед экзаменом, откуда брать вопросы для собеседования и что положить в портфолио. Всё остальное из пятисот с лишним звёзд сюда не попало — отсутствие фильтра и есть главная проблема больших коллекций. Отмечай пройденное галочкой: состояние сохраняется в браузере, отметки видны и с телефона, если открывать в том же браузере.

Если открыл впервые — порядок такой

  1. Замер. Пройти тренажёр с фильтром junior, не открывая ответы. Без цифры дальше всё вслепую.
  2. Дыры. Что провалил — закрыть по разделу «Курсы и программы», а не подряд.
  3. Руками. Одна лаба в день из «Практика и лабы». Смотреть видео — не считается.
  4. Портфолио. Один проект из «Проекты для портфолио», доведённый до конца. Весит больше сертификата.
  5. Экзамен. Только когда предыдущее сделано: CKA закрывает вопрос о Kubernetes в резюме.

Ничего не нашлось — измени запрос или сними фильтр.

Список собран из моих звёзд на GitHub и отфильтрован: осталось то, что имеет отношение к работе и подготовке. Отобранное по темам с порядком прохождения — на странице материалов, вопросы — в тренажёре.

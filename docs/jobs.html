Вакансии

Что просит рынок Алматы

Запросы уходят в открытый API hh прямо из твоего браузера — ни сервера, ни ключей, ни моего участия. Дальше страница делает то, чего hh не делает: вытаскивает из вакансий технологии, считает, как часто каждую требуют, и сопоставляет это с твоими оценками в тренажёре. Получается не «модно учить ArgoCD», а «его требуют в тридцати из пятидесяти вакансий, а у тебя по нему нули — вот урок».

Как читать метки. Процент — это сколько требований вакансии ты закрываешь, а не «насколько она хорошая». Сто процентов часто означает вакансию ниже твоего уровня: если весь список требований — Proxmox, VMware, Zabbix и Windows, ты закроешь его целиком, но она ведёт назад. Поэтому есть вторая метка: целевая — есть современный стек и ты его в основном закрываешь, рост — стек целевой, но нового много, сисадминская — Kubernetes, IaC и наблюдаемости в требованиях нет вообще. Сортировка идёт по этой метке, а не по проценту: сверху целевые, потом дающие рост, сисадминские — в конце.
Почему запрос идёт из браузера, а не с сервера. hh блокирует облачные адреса: из дата-центра его API отдаёт 403, а обычная страница поиска — капчу. С домашнего адреса в Казахстане всё проходит. Побочный плюс: данные всегда свежие, ничего не кэшируется в репозитории. Если запрос не пройдёт — ниже появится ошибка и ссылка на обычный поиск hh, а не пустой экран.

Где ещё смотреть

У этих сайтов нет открытого API для поиска: у LinkedIn его нет вовсе и вакансии спрятаны за входом, у остальных поиск открыт, но только в браузере. Поэтому здесь честные ссылки с уже подставленными фильтрами — открываются там, где ты уже залогинен.

Отклики отмечаются здесь и живут в браузере. Кнопка «в дневник» создаёт заготовку записи на странице дневника — туда потом дописываются вопросы и результат. Что подтянуть по требованиям рынка — в курсах и тренажёре.

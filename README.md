### Про тренажёр

Каждый вопрос устроен так: что на самом деле проверяет интервьюер → ответ →
уровень глубины, отличающий middle от junior → типичная ошибка, на которой
проваливают.

На странице ответы скрыты. Прочитал вопрос — **скажи ответ вслух**, поставь себе
оценку от 0 до 2 и только потом сверься. Страница считает долю уверенных ответов
по каждому разделу: это честный замер уровня, потому что ощущения обманывают в
обе стороны.

С клавиатуры: `Space` — показать ответ, `0` `1` `2` — оценка и переход к
следующему вопросу, `J` / `K` — листать, `X` — снять оценку, `/` — поиск.
Прогресс сохраняется в браузере.

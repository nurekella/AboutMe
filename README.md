### Про тренажёр

Каждый вопрос устроен так: грейд (junior / middle / senior) → что на самом деле
проверяет интервьюер → ответ → уровень глубины, отличающий middle от junior →
типичная ошибка, на которой проваливают.

На странице ответы скрыты. Прочитал вопрос — **скажи ответ вслух**, поставь себе
оценку от 0 до 2 и только потом сверься. Страница считает долю уверенных ответов
по каждому разделу и по каждому грейду: это честный замер уровня, потому что
ощущения обманывают в обе стороны.

Грейд считается закрытым, когда двоек в нём 70% и больше. Порядок один: junior
целиком, потом middle, senior — по остаточному принципу. Вопросы фильтруются по
грейду, и экзамен можно запустить только по выбранному грейду.

С клавиатуры: `Space` — показать и скрыть ответ, `0` `1` `2` — оценка и переход к
следующему вопросу, `J` / `K` — листать, `X` — снять оценку, `/` — поиск.

Ещё есть **режим экзамена** (случайные вопросы, таймер, ответ открывается только
после оценки), **интервальное повторение** (фильтр «повторить»: ноль вернётся
через день, единица через три, двойка через две недели), **карточный режим** для
телефона и **перенос прогресса** между устройствами кодом.
